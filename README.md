# HW3: Генератор и Аналитик данных

Этот проект представляет собой автоматизированную систему для генерации данных и их анализа с использованием Docker-контейнеров.

## Структура проекта
- `data/` — директория для хранения входных данных (`data.csv`) и результатов анализа (`report.html`).
- `generator/` — исходный код и `Dockerfile` для контейнера-генератора.
- `reporter/` — исходный код и `Dockerfile` для контейнера-аналитика.
- `run.sh` — скрипт для управления всеми процессами.

## Как использовать
Для работы с проектом используйте скрипт `./run.sh` с соответствующей командой:

### 1. Подготовка
- `create_local_data` — создать папку `data/`, если она отсутствует.
- `clear_data` — удалить все сгенерированные файлы из папки `data/`.

### 2. Генератор
- `build_generator` — собрать образ контейнера-генератора.
- `run_generator` — запустить генерацию данных (создает `data/data.csv`).

### 3. Аналитик
- `build_reporter` — собрать образ контейнера-аналитика.
- `run_reporter` — запустить анализ данных (создает `data/report.html`).

### 4. Отладка
- `structure` — вывести структуру проекта.
- `inside_generator` — запустить контейнер генератора и просмотреть содержимое папки `data`.
- `inside_reporter` — запустить контейнер аналитика и просмотреть содержимое папки `data`.
